Exception Handling in Java

What are Exceptions?

In Java, an exception is an event that disrupts the normal flow of a program's instructions. When an error occurs within a method, the method creates an exception object and hands it off to the runtime system.

Exceptions are used to handle errors and other exceptional events in a structured way. The Java exception handling mechanism provides the following benefits:

  • Separates error-handling code from regular code
  • Propagates errors up the call stack
  • Groups and differentiates error types

Analogy: Think of exceptions as traffic signals. Green light means normal flow (no exceptions), yellow light means caution (potential issues), and red light means stop (exception occurred that needs handling).

Checked vs. Unchecked Exceptions

Java exceptions are categorized into two main types:

Checked Exceptions

These are exceptions that are checked at compile-time. The compiler ensures that these exceptions are either caught or declared in the method signature using the throws keyword.

import java.io.*;

public class CheckedExceptionExample {
    public void readFile() throws IOException {
        FileReader file = new FileReader("test.txt");
        BufferedReader br = new BufferedReader(file);
        System.out.println(br.readLine());
    }
}

Unchecked Exceptions

These are exceptions that are not checked at compile-time. They occur at runtime due to programming errors like logic mistakes or improper use of an API.

public class UncheckedExceptionExample {
    public static void main(String[] args) {
        int[] numbers = {1, 2, 3};
        System.out.println(numbers[5]); // ArrayIndexOutOfBoundsException
    }
}

The try-catch-finally block

Java provides a robust mechanism to handle exceptions using try, catch, and finally blocks.

Basic try-catch

public class TryCatchExample {
    public static void main(String[] args) {
        try {
            int result = 10 / 0; // This will cause ArithmeticException
        } catch (ArithmeticException e) {
            System.out.println("Error: Cannot divide by zero!");
        }
    }
}

Multiple catch blocks

public class MultipleCatchExample {
    public static void main(String[] args) {
        try {
            int[] numbers = new int[5];
            numbers[10] = 50; // ArrayIndexOutOfBoundsException
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Array index is out of bounds!");
        } catch (Exception e) {
            System.out.println("Some other exception occurred");
        }
    }
}

try-catch-finally

public class FinallyExample {
    public static void main(String[] args) {
        try {
            int result = 10 / 2;
            System.out.println("Result: " + result);
        } catch (ArithmeticException e) {
            System.out.println("Arithmetic exception occurred");
        } finally {
            System.out.println("This block always executes");
        }
    }
}

Throwing Exceptions (throw keyword)

The throw keyword is used to explicitly throw an exception from a method or any block of code. You can throw either checked or unchecked exceptions.

Throwing Unchecked Exception

public class ThrowExample {
    public static void validateAge(int age) {
        if (age < 18) {
            throw new IllegalArgumentException("Age must be 18 or older");
        } else {
            System.out.println("Age is valid");
        }
    }

    public static void main(String[] args) {
        try {
            validateAge(15);
        } catch (IllegalArgumentException e) {
            System.out.println("Exception: " + e.getMessage());
        }
    }
}

Throwing Checked Exception

import java.io.IOException;

public class CheckedThrowExample {
    public static void processFile(String filename) throws IOException {
        if (filename == null || filename.isEmpty()) {
            throw new IOException("Filename cannot be empty");
        }
        System.out.println("Processing file: " + filename);
    }

    public static void main(String[] args) {
        try {
            processFile("");
        } catch (IOException e) {
            System.out.println("IO Exception: " + e.getMessage());
        }
    }
}

Complete Example

public class BankAccount {
    private double balance;

    public BankAccount(double initialBalance) {
        if (initialBalance < 0) {
            throw new IllegalArgumentException("Initial balance cannot be negative");
        }
        this.balance = initialBalance;
    }

    public void withdraw(double amount) {
        try {
            if (amount <= 0) {
                throw new IllegalArgumentException("Withdrawal amount must be positive");
            }
            if (amount > balance) {
                throw new IllegalArgumentException("Insufficient funds");
            }
            balance -= amount;
            System.out.println("Withdrawal successful. New balance: " + balance);
        } catch (IllegalArgumentException e) {
            System.out.println("Withdrawal failed: " + e.getMessage());
        } finally {
            System.out.println("Transaction attempt completed");
        }
    }

    public static void main(String[] args) {
        try {
            BankAccount account = new BankAccount(1000);
            account.withdraw(500);
            account.withdraw(700); // This will throw an exception
        } catch (Exception e) {
            System.out.println("Account creation failed: " + e.getMessage());
        }
    }
}
