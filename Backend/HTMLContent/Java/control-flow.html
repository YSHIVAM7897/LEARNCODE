Control Flow Statements in Java

Control flow statements are fundamental building blocks in Java that allow you to control the order in which statements are executed in your program. They enable decision-making, looping, and branching in your code.

Conditional Statements (if, if-else, else-if ladder)

if Statement

The if statement is the most basic control flow statement. It executes a block of code only if a specified condition is true.

int age = 18;

if (age >= 18) {
    System.out.println("You are eligible to vote.");
}

if-else Statement

The if-else statement provides an alternative block of code to execute when the condition is false.

int score = 75;

if (score >= 60) {
    System.out.println("You passed the exam.");
} else {
    System.out.println("You failed the exam.");
}

else-if Ladder

The else-if ladder allows you to test multiple conditions in sequence.

int marks = 85;

if (marks >= 90) {
    System.out.println("Grade: A");
} else if (marks >= 80) {
    System.out.println("Grade: B");
} else if (marks >= 70) {
    System.out.println("Grade: C");
} else if (marks >= 60) {
    System.out.println("Grade: D");
} else {
    System.out.println("Grade: F");
}

Switch Statement

The switch statement allows a variable to be tested for equality against a list of values. Each value is called a case.

int day = 3;
String dayName;

switch (day) {
    case 1:
        dayName = "Monday";
        break;
    case 2:
        dayName = "Tuesday";
        break;
    case 3:
        dayName = "Wednesday";
        break;
    case 4:
        dayName = "Thursday";
        break;
    case 5:
        dayName = "Friday";
        break;
    case 6:
        dayName = "Saturday";
        break;
    case 7:
        dayName = "Sunday";
        break;
    default:
        dayName = "Invalid day";
        break;
}

System.out.println("Day: " + dayName);

Note: Starting from Java 14, switch expressions were introduced, allowing for more concise syntax:

String dayName = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    case 4 -> "Thursday";
    case 5 -> "Friday";
    case 6 -> "Saturday";
    case 7 -> "Sunday";
    default -> "Invalid day";
};

Loops (for, while, do-while)

for Loop

The for loop is used when you know exactly how many times you want to loop through a block of code.

// Print numbers from 1 to 5
for (int i = 1; i <= 5; i++) {
    System.out.println("Number: " + i);
}

// Enhanced for loop (for-each loop)
int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println("Number: " + num);
}

while Loop

The while loop loops through a block of code as long as a specified condition is true.

// Print numbers from 1 to 5 using while loop
int i = 1;
while (i <= 5) {
    System.out.println("Number: " + i);
    i++;
}

do-while Loop

The do-while loop is similar to the while loop, but it executes the code block at least once before checking the condition.

// Print numbers from 1 to 5 using do-while loop
int i = 1;
do {
    System.out.println("Number: " + i);
    i++;
} while (i <= 5);

Loop Comparison

Loop Type When to Use Characteristics
for When you know the exact number of iterations Initialization, condition, and increment in one line
while When the number of iterations is unknown Condition is checked before execution
do-while When you need to execute at least once Condition is checked after execution

Jump Statements (break, continue)

break Statement

The break statement is used to exit a loop or switch statement prematurely.

// Break out of a loop when a condition is met
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break; // Exit the loop when i is 5
    }
    System.out.println("Number: " + i);
}
// This will print numbers 1 to 4 only

continue Statement

The continue statement skips the current iteration of a loop and proceeds to the next iteration.

// Skip even numbers in a loop
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue; // Skip even numbers
    }
    System.out.println("Odd number: " + i);
}
// This will print only odd numbers: 1, 3, 5, 7, 9

Labeled break and continue

Java also supports labeled break and continue statements for nested loops.

// Using labeled break to exit outer loop
outerLoop:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == 2 && j == 2) {
            break outerLoop; // Break out of both loops
        }
        System.out.println("i=" + i + ", j=" + j);
    }
}

Complete Example: Control Flow in Action

public class ControlFlowExample {
    public static void main(String[] args) {
        // Conditional statement example
        int number = 15;
        
        if (number % 2 == 0) {
            System.out.println(number + " is even.");
        } else {
            System.out.println(number + " is odd.");
        }

        // Switch statement example
        int day = 3;
        switch (day) {
            case 1:
                System.out.println("Monday");
                break;
            case 3:
                System.out.println("Wednesday");
                break;
            default:
                System.out.println("Other day");
        }

        // Loop example with break and continue
        System.out.println("Numbers 1 to 10, skipping 5 and stopping at 8:");
        for (int i = 1; i <= 10; i++) {
            if (i == 5) {
                continue; // Skip 5
            }
            if (i == 8) {
                break; // Stop at 8
            }
            System.out.print(i + " ");
        }
    }
}
