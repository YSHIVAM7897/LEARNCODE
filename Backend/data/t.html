React useState() Hook

The useState hook in React is a function that allows functional components to manage and update state variables. It was introduced in React 16.8 as part of React Hooks, enabling developers to use React features like state without needing to write class components.

Syntax: 

const [state, setState] = useState(initialValue);

  • state: The current state value.
  • setState: A function used to update the state.
  • initialValue: The initial value of the state.

How does useState() work?

  • Importing the Hook: You first need to import useState from the React library: 
    import React, { useState } from 'react';
  • Initial State: When you call useState(initialValue), it creates a state variable and an updater function. 
    const [count, setCount] = useState(0);
  • Declaring State Variables: You can declare state variables inside your functional component using the useState hook. For example: 
    const [count, setCount] = useState(0);
    In this example, count is the state variable holding the current value (initialized to 0), and setCount is the function used to update count.
  • Updating State: To change the value of the state variable, you must use the setter function provided by useState (e.g., setName). When this setter function is called with a new value, React re-renders the component with the updated state. 
    const [name, setName] = useState('');

When to use the useState Hook?

  • When you want to add state to functional components.
  • When you need to manage simple state that doesn't require complex logic.
  • When you want to keep your components concise and easy to read.
  • When you want to avoid the boilerplate code associated with class components.
